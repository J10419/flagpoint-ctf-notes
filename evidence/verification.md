# 測試紀錄

日期：2026-11-05。環境：Windows、Node.js v24.15.0。

## 自動測試

執行 `npm test`，12 組測試通過。

涵蓋內容格式、檔案命名、輸出路徑保護、HTML 結構與連結、可重現建置、文字跳脫、搜尋、Base64 解碼與測驗判定。

擴充測試會在暫存目錄連續新增兩篇文章，檢查文章頁與首頁目錄是否自動更新，不修改正式內容。

## 瀏覽器檢查

| 項目 | 結果 |
| --- | --- |
| 搜尋 `base64` | 顯示 Base64 筆記 |
| 相同搜尋加上 Web 分類 | 顯示無結果提示 |
| 按「顯示全部筆記」 | 清除搜尋與分類，恢復全部筆記 |
| Base64 解碼 | 正確顯示 `flag{first_step}` |
| 輸入 `!not-base64` | 顯示格式錯誤 |

| 練習答案 | 可展開答案與解釋 |
| 導覽 | 首頁及三篇文章可互相導覽 |
| 桌機 1280 × 900 | 雙欄首頁與文章卡片顯示正常 |
| 手機 390 × 844 | 首頁及三篇文章無整頁水平溢位 |
| 瀏覽器主控台 | 檢查時無錯誤訊息 |
